## 🎯 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal. O objetivo deste site é centralizar e apresentar de forma interativa minha jornada profissional, habilidades técnicas e, principalmente, os projetos práticos que desenvolvo envolvendo **Análise de Dados, Visualização e Cloud Computing**.

### ✨ Principais Funcionalidades
- **Apresentação Pessoal:** Resumo sobre minha transição e foco na área de dados.
- **Vitrine de Projetos:** Cards detalhados com links para repositórios e dashboards interativos.
- **Design Responsivo:** Adaptado para leitura em desktops, tablets e smartphones.
- **Seção de Contato:** Links diretos para minhas redes profissionais e WhatsApp.
